# Город, который забыл свой праздник · v0.2

Рабочий прототип математического адвента для детей 10–13 лет. Десять открытий постепенно возвращают старинному зимнему городу адреса, музыку, снег, свет и общий праздничный замысел.

## Открыть

- Новая версия после включения GitHub Pages: https://nataliedali.github.io/advent2026/
- Первая версия: https://nataliedali.github.io/advent2026/archive/v0.1-2026-10-31/
- Репозиторий: https://github.com/NatalieDali/advent2026

Если Pages ещё не включён: **Settings → Pages → Source: Deploy from a branch → main → / (root) → Save**. Наличие файлов на GitHub само по себе не публикует сайт.

Сборка и зависимости не нужны. Для локального просмотра запустите из этой папки `python3 -m http.server 8765 --bind 127.0.0.1` и откройте http://127.0.0.1:8765/ .

## Что изменилось

- 1 декабря — пролог; десять основных дел в дни 2, 4, 6, 8, 10, 12, 14, 16, 18 и 20. После каждого — письмо и вторая подсказка. 22-го — сбор досье, 23-го — главный финал, 24-го — развязка и подарки без обязательной дополнительной задачи.
- В окошке задачи показана только первая подсказка; вторая находится только в отдельном окошке следующего дня. Расписание работает независимо от состояния решения. Тексты подсказок появятся вместе с утверждёнными условиями.
- Дата открывает окошко; ключ и изменение города выдаются только за решение готового дела.
- Кармашек содержит десять мест, сведения ключей и ссылки на исходные дела.
- Город состоит из независимых слоёв: архивная опись, письма, мозаика, каталог, адреса, музыка, падающий снег, фонари/окна, механизм, часы.
- Снег привязан к делу 14-го дня, свет — к 16-му. Музыка включается пользователем; доступны две простые синтезированные мелодии. Снег и движение можно отключить. Системное уменьшение анимации учитывается.
- Финальное окошко открывается по календарю и при нуле ключей. При недостатке предлагает возврат к делам. Макет досье показывает четыре группы сведений при восьми примерах ключей.

## Авторский просмотр

По умолчанию включён, пока приложение наполняется. **Настройки → Авторский просмотр**:

1. Ползунком выберите календарный день.
2. Отметьте отдельные открытия или нажмите «Показать все открытия».
3. Закройте настройки и посмотрите город, кармашек и финальное досье.

Примеры сохраняются отдельно от прохождения. Они **не выдают настоящие ключи**, не попадают в файл прогресса и не отмечают задачи решёнными. Эффект из будущего скрывается при выборе более раннего дня. Выключение авторского просмотра возвращает реальный календарь и прогресс участника.

## Что ещё не готово

**Все десять основных математических дел — редакторские заготовки**, а не новые сочинённые задачи. Не утверждены условия, ответы и карточки-ключи. Посещение заготовок не даёт ключей. Сохранённое пробное дело про девять окон доступно в разделе «Об истории» и в настройках: оно проверяет форму ввода, две подсказки и объяснение, но не входит в десять дел, не выдаёт ключей и не меняет город.

**Финал — макет взаимодействия, а не готовая математическая задача.** Наличие восьми примеров открывает только вид досье, не доказывает возможность решения с любыми восемью ключами. Конкретную конструкцию предстоит проверить на всех 45 наборах из восьми и 120 наборах из семи. Проверка финального ответа пока не подключена. В финале не запланирована подсказка на следующий день: ключи должны выполнять её роль.

**Подарочные файлы ещё готовятся.** На 24-й день предусмотрены PDF задач без ответов и объёмная печатная открытка. Кнопки скачивания отключены, пока нет настоящих файлов. Нет поддельных загрузок или сертификата вместо подарка.

В рабочей папке на компьютере этот репозиторий занимает только `site/`. Остальные материалы проекта находятся снаружи и не публикуются.

## Подключение утверждённой задачи

В записи соответствующего дня в `content.js` указать `status: 'ready'`, `question`, `answer`, `hints` из двух текстов, `explanation`, `key: {title, text}`. Текущие проверяющие форматы: `{type:'number',value:42}`, `{type:'text',value:'слово',accepted:['слово','вариант']}`, `{type:'set',value:[1,4,9]}`. Числа и наборы проверяются строго; для текста нормализуются регистр, пробелы и ё/е. Другие формы интерактивных задач требуют отдельной реализации. Приведённые значения — примеры формата, не задания.

В авторском просмотре настоящие ответы не выдают ключи. Готовые задачи проходятся в календарном режиме; для разработки правила отдельно тестируются с заданным временем.

## Сохранения и архив

- v0.2: `lichtenbourg-advent-v2`; авторские примеры: `lichtenbourg-author-v2`.
- v0.1: прежний ключ `lichtenbourg-advent-v1`, архивная версия использует его без изменений.
- Сброс v0.2 не удаляет старое прохождение. Сохранение v0.1 не преобразуется в новые ключи: структура календаря изменилась.
- Экспорт/импорт JSON v0.2 переносит реальное прохождение и пользовательские предпочтения. Данные авторского просмотра не экспортируются. Импорт заменяет текущее прохождение.
- При смене устройства или домена нужна ручная загрузка файла. Очистка браузера может удалить прогресс.
- Период календаря: 1 декабря 2026 — 31 января 2027 включительно, Europe/Berlin. Даты предварительные.

## Проверка

Без установки дополнительных библиотек: `node tests/regression.cjs` при наличии Node.js. Для просмотра готового сайта Node пользователю не нужен.

Проверки покрывают состав календаря, расписание эффектов и подсказок, границы доступа по времени Берлина, проверку ответов, запрет выдачи ключей за закрытое или черновое дело, отсутствие дубликатов наград, перенос сохранений и контрольные суммы первой версии. Браузерная проверка дополнительно охватывает визуальные слои, музыку, пробное дело и состояния финального досье.

## Ограничения размещения

Прототип работает полностью в браузере: нет регистрации, оплаты, сервера, защищённого календарного доступа или скрытых ответов. Исходники публичны, часы устройства влияют на календарь. Для коммерческой версии потребуются отдельные решения по доступу и подходящий хостинг с учётом [правил GitHub Pages](https://docs.github.com/en/site-policy/github-terms/github-terms-for-additional-products-and-features#pages). Шрифты загружаются из Google Fonts; при недоступности применяются системные.
