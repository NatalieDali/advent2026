# Тайна пропавшей полуночи

Рабочий прототип математического адвента для детей 10–13 лет. Старинный рождественский город Лихтенбург, Бюро невозможных событий и расследование исчезнувшей минуты. Мир, названия и распределение содержания — редактируемые рабочие решения.

## Реализовано

- 24 календарных дня: 10 мест под основные математические дела, 13 сюжетных дней и отдельный финал 24 декабря.
- Полностью проходимое демонстрационное дело первого дня: проверка ответа, три последовательные подсказки, математическое объяснение и выдача улики.
- Письмо второго дня. Дни 3–24 — явно обозначенные заготовки.
- Архив полученных улик и открытых документов.
- Доступность по календарю, независимо от решения предыдущих задач, и демонстрационный режим для автора.
- Локальное сохранение, экспорт/импорт прогресса в JSON и сброс с подтверждением.
- Адаптивное оформление, клавиатурная навигация, поддержка уменьшенной анимации.
- Собственная SVG-иллюстрация города, без сторонних фотографий и изображений.

Демонстрационная задача про переключение окон — классическая задача о делителях и квадратах, а не заявка на оригинальную задачу коммерческого продукта. Она нужна для проверки технического сценария и может быть заменена.

## Открытие и публикация

Проект не требует сборки, npm, сервера приложения или базы данных.

Для GitHub Pages: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → / (root) → Save**.

После успешной публикации ожидаемый адрес: https://nataliedali.github.io/advent2026/ . До включения Pages адрес не работает.

Локальный просмотр: запустите `python3 -m http.server 8765 --bind 127.0.0.1` из папки проекта и откройте http://127.0.0.1:8765/ . Установка Python пользователю для просмотра опубликованного сайта не нужна.

## Где редактировать

| Файл | Назначение |
| --- | --- |
| `content.js` | Даты, часовой пояс, дни, условия, ответы, подсказки, объяснения и улики |
| `app.js` | Интерфейс, проверка ответа, календарь и прогресс |
| `styles.css` | Цвета, шрифты, размеры, адаптивное оформление |
| `assets/city.svg` | Иллюстрация зимнего города |
| `index.html` | Основная страница, меню и настройки |

Для замены пробного дела меняются поля первого элемента `days`: `intro`, `question`, `answer`, `hints`, `explanation`, `clue`. Текущий проверяющий механизм поддерживает набор разных номеров окон от 1 до 9. Для задач с иным форматом ответа потребуется добавить соответствующий тип проверки и интерфейс; произвольные форматы задач пока не реализованы.

Готовый сюжетный день содержит `type: 'story'`, `ready: true`, `place`, `paragraphs` и `note`. Оставьте `ready` выключенным, пока материал не готов. При добавлении новых типов дел нужно расширить отображение в `app.js`.

## Даты и прогресс

Период открытия: с **1 декабря 2026**, по одному дню. Доступ завершается **31 января 2027 включительно**, часовой пояс **Europe/Berlin**. Эти значения — настройки прототипа, не утверждённые продуктовые сроки. Демонстрационный режим по умолчанию включён. Его можно переключить в настройках, не удаляя прогресс.

Прогресс хранится в `localStorage` с ключом `lichtenbourg-advent-v1`. В JSON нет имени, почты или других данных ребёнка. Очистка данных браузера удаляет прогресс. Другая ссылка/домен или устройство имеют отдельное хранилище: для переноса скачайте прогресс и загрузите его на новом адресе. Импорт заменяет текущее прохождение. Изменение содержания уже пройденных дней может требовать сброса или миграции сохранений.

## Ограничения

- Это технически работающий каркас, а не готовый 24-дневный образовательный продукт. Девять основных дел, промежуточные письма, финальная задача и подарок ещё предстоит разработать.
- Нет аккаунтов, оплаты, сервера, облачной синхронизации, защиты ответов или закрытого доступа после покупки. Календарь использует часы устройства. Демо-режим доступен всем посетителям.
- Доступ по датам в браузере не является защитой содержания. Исходники и ответы открыты в публичном репозитории.
- Основные шрифты загружаются из Google Fonts. Без сети применяются системные шрифты; приложение сохраняет функциональность.
- GitHub Pages используется для демонстрации проекта. Перед коммерческим запуском требуется выбрать подходящий хостинг и модель доступа с учётом [правил GitHub Pages](https://docs.github.com/en/site-policy/github-terms/github-terms-for-additional-products-and-features#pages).

## Проверка перед наполнением

1. Откройте первое дело, введите неверный ответ, затем возьмите подсказки.
2. Введите `9 1 4`: порядок не важен. Проверьте появление улики в архиве.
3. Обновите страницу: решение, улика и прочитанные дни должны сохраниться.
4. Скачайте прогресс, сбросьте его, загрузите сохранённую копию.
5. Выключите демо-режим: до 1 декабря окошки должны быть закрыты. Включите обратно.
6. Откройте дни 2, 3 и 24: письмо и заготовки должны явно отличаться.

Следующий этап: утвердить архитектуру задач и финала, затем добавлять содержание партиями, сохраняя 10 основных задач и отдельный финал.
